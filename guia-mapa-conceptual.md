# Guía para construir un mapa conceptual con IA

Esta guía sirve para descubrir qué necesitas aprender sobre un tema que ya puedes nombrar y convertirlo en un mapa conceptual documentado.

## FASE 0 — Criterio de fuentes

1. Pregunta al usuario qué concepto, frase o palabra se utilizará para la búsqueda.
2. Utiliza únicamente fuentes confiables, validadas y destinadas al estudio.
3. No utilices como base principal Wikipedia, TikTok, foros ni publicaciones de poca confianza.

## FASE 1 — Recolección de conceptos

1. Consulta al menos **30 sitios web** sobre el tema.
2. Recopila los conceptos encontrados tal como aparecen.
3. Registra las fuentes de donde obtuviste los conceptos mediante un listado de URLs agrupado por lo investigado.
4. Pregunta al usuario dónde quiere registrar esta información.
5. En esta fase **no construyas todavía una explicación completa**. El objetivo es recopilar y documentar los conceptos.

## FASE 2 — Construcción del mapa conceptual

1. Utilizando exclusivamente los conceptos recopilados en la Fase 1, construye un mapa conceptual completo.

2. Identifica y organiza:
   - conceptos
   - relaciones
   - jerarquías
   - agrupaciones
   - vacíos de documentación
   - cualquier otro elemento necesario para construir un mapa conceptual coherente y completo.

3. Documenta el mapa conceptual **en texto**. Describe su estructura, relaciones y jerarquías. No generes todavía una imagen ni un mapa visual.

4. Pregunta al usuario dónde quiere documentar esta descripción.

## FASE 3 — Generación del mapa visual

Una vez construido y documentado el mapa conceptual, crea un prompt dirigido a una IA especializada en mapas conceptuales.

El objetivo de esta segunda IA será únicamente **representar visualmente el mapa que ya fue construido**.

La IA deberá:

- conservar intactas las etiquetas;
- respetar las relaciones y jerarquías definidas;
- no añadir conceptos nuevos;
- no realizar predicciones;
- no hacer inferencias adicionales;
- limitarse a representar visualmente el mapa proporcionado.

Finalmente, entrega al usuario el prompt listo para utilizar en la herramienta de mapas conceptuales.
